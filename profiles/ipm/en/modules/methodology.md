## Rhetorical moves

- Older log studies explain record structure, sorting/reconstruction, duplicate/agent filtering, variable definitions and coded categories; controlled studies explain task/instrument/system operations; intent papers derive taxonomy/features and verify rules; persona studies explain latent patterns/weights and collapse criteria. Treat these as distinct pipelines, not a pooled APG recipe.

## Organization

- Overview → input representation → transformation → output/evaluation. Journal system articles use numbered subsections and diagrams/pseudocode; some original methods combine setup and analysis, which is retained rather than split artificially.

## Language and stance

- Explicit action verbs make operational choices traceable; present describes mechanisms and past recounts execution. Cite reused algorithms/tools and explain unavailable proprietary parts. Historical VBA/Windows/MSN/Google Directory details are provenance, not required modern implementation.

## Evidence and citations

- Workflow figures and pseudocode explain reproducibility; worked examples define states or categories. Tables/equations have text-layer corruption and grid spillover, so numeric/formula reuse must consult the original. Manual agreement, consensus and a generated reference are not external truth.

## Cross-lingual transferable patterns

- Transfer representation → processing → output → operational verification. Target-language terminology/notation follows user research context; no Chinese-method convention is evidenced.

## Avoid
